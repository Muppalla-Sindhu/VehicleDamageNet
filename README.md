# 🚗 Vehicle Damage Detection System (VehicleDamageNet)

An AI-powered system for automated vehicle damage detection, classification, severity analysis, and repair cost estimation using YOLOv8 and Computer Vision.

---

## 📌 Overview
This project aims to replace manual vehicle inspection with an intelligent deep learning-based system. It detects damages such as scratches, dents, broken glass, and wrecks from images and provides severity analysis along with estimated repair costs.

---

## 🚀 Features
- 🔍 Real-time damage detection using YOLOv8
- 🚘 Multi-vehicle support (Car, Bike, Truck)
- 🛠 Damage classification (Scratch, Dent, Broken Glass, Wreck)
- 📊 Severity estimation (Minor, Moderate, Severe)
- 💰 Repair cost estimation
- 🖼 Annotated output with bounding boxes
- 🌐 User-friendly Gradio interface
- 📁 CSV logging for results

---

## 🧠 Technologies Used
- Python
- OpenCV
- NumPy
- Ultralytics YOLOv8
- Gradio

---

## 🏗 System Architecture
1. Image Input  
2. Preprocessing

5. Severity Mapping  
6. Cost Estimation
